# Stellar Burgers – Web Application for Food Ordering

Stellar Burgers is a web application where users can biuld their own space-themed burgers, place orders through personal account, and view order history.

This project focuses on building a structured frontend architecture with state management, routing, and API integration.

## 📌 Key Features

* User registration and authentication with protected routes
* Profile management with editing capabilities
* Real-time order feed
* Modal windows with detailed information

## 🛠️ Tech Stack

* TypeScript / JavaScript
* React, React Router
* Redux
* HTML5 / CSS3
* Stylelint

## 🚀 Setup & Installation

### Installation

```bash
npm install
```

### Development Server

```bash
npm run start
```

### Testing

The project uses Jest for unit testing and `@testing-library/jest-dom` for DOM matchers.

Run tests (single run):

```bash
npm run test
```
